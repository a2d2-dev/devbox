# fnOS 功能盘点

> 调研日期：2026-08-23
>
> 调研方式：使用 `agent-browser` 登录用户提供的 fnOS 实例，基于页面无障碍树、可见控件和只读网络请求进行观察性盘点。未执行安装、创建、保存、启停、删除、清空、恢复、更新、重置等写操作。登录凭据、设备 ID、内网地址、MAC 地址和日志来源地址均未记录。

## 结论摘要

fnOS 采用桌面式窗口管理器作为主入口，当前实例提供 9 个核心应用：文件管理、系统设置、应用中心、下载、Docker、备份、资源管理、日志、回收站。系统设置再细分为 14 个一级配置页。

当前实例尚未创建存储空间，Docker 也未配置存储路径，因此文件内容、实际备份任务、容器运行态及部分应用安装后功能无法安全验证。以下条目只记录 `agent-browser` 实际可见的功能和明确空状态，不把未操作的配置项描述为已启用。

## 1. 登录、桌面与引导

- 登录：用户名、密码、显示密码、保持登录、忘记密码、登录。
- 桌面式窗口管理：文件管理、系统设置、应用中心、下载、Docker、备份、资源管理、日志、回收站。
- 新手引导：创建存储空间；选择安装飞牛相册与飞牛影视；一键安装；配置 FN Connect；设置安全邮箱。
- 实时状态：CPU、RAM、网络吞吐、存储读写、运行时长、存储空间状态。

## 2. 文件管理与回收站

- 文件来源：我的文件、团队文件、外接存储、远程挂载、应用文件。
- 分享与访问：他人共享、我的共享、外链管理、最近访问、我的收藏。
- 管理入口：回收站、管理员视角、设置。
- 基础操作：搜索、排序、前进/后退、刷新；选中文件后支持下载、删除、更多操作。
- 回收站按“我的文件 / 团队文件”区分，支持搜索和文件工具栏。
- 当前限制：未创建存储空间，个人文件、团队文件和回收站只显示前置条件与“存储空间管理”入口。

## 3. 系统设置

### 3.1 设备信息

- 设备名称、设备 ID、系统版本、运行时间。
- 系统安装空间、存储空间状态、硬件与网口摘要。
- 检查更新、飞牛账号登录、FN Connect 状态、创建存储空间入口。

### 3.2 用户管理

- “用户 / 用户组”双视图与用户搜索。
- 新增用户、编辑、更多操作。
- 用户角色与 SSH 权限标识。
- 用户和存储空间、团队文件夹、用户组之间的授权关系。

### 3.3 存储与硬盘

- 存储空间列表与创建存储空间。
- SSD 缓存加速。
- 内置/外接硬盘分类、容量、介质、接口、健康状态、分区和用途。
- 硬盘休眠设置。

### 3.4 网络与远程访问

- 网口连接状态、实时速率、DHCP、IPv4/IPv6、网关、DNS、双工与 MTU。
- FN Connect：FN ID、浏览器/App 远程访问与高级设置。
- DDNS：新增配置和立即更新。
- 外链设置：分享域名、最大上传/下载速度。
- SSH：管理员访问、端口和高级设置。

### 3.5 安全性

- 访问设置：HTTP/HTTPS 端口、访问码。
- 账号安全：强制双重验证。
- 防护：异常 IP 自动封禁及规则编辑，覆盖 SSH。
- 防火墙：启用状态、入站/出站规则和高级设置。
- 证书：新增证书、服务配置、系统自签证书及自动续签信息。

### 3.6 文件共享协议

- SMB：共享访问、主机名、Time Machine 与目标文件夹。
- WebDAV：HTTP/HTTPS 端口及高级设置。
- FTP/FTPS：服务端口、可见文件夹与高级设置。
- NFS：共享路径和匿名访问安全提示。
- DLNA：多媒体文件夹、支持格式和高级设置。

### 3.7 其他系统设置

- 许可证：全部/有效/失效分类、账号登录和购买入口。
- 通知设置：SMTP 邮件通知，用于 2FA 紧急验证码和密码重置。
- 硬件和电源：UPS 支持与断电安全关机。
- 更新和还原：系统更新、系统配置、系统重置、自动更新。
- 应用：全部应用与默认应用。

## 4. 应用中心

- 导航：全部、最新发布、已安装、分类、设置、手动安装。
- 分类：影音娱乐、摄影录像、AI、下载、备份同步、开发工具、实用效率、生活、游戏、驱动。
- 来源：飞牛官方与社区应用。
- 应用卡片提供名称、分类和安装入口。
- 官方列表可见影视、相册、文件快照、虚拟机、iSCSI、Office 文档、安全中心、百度网盘、飞牛同步、文本编辑器等。
- 社区列表可见下载器、媒体服务、开发工具、AI、网络与同步类应用。

## 5. 下载中心

- 状态筛选：全部、下载、完成、做种、活动、空闲、暂停、错误。
- 添加任务、开始、暂停、删除、搜索任务名称、任务详情。
- 管理员视角。
- 上下行实时速率与累计流量。

## 6. Docker

- 概览：服务状态、运行项目数、容器数和空闲状态。
- Docker 服务开关、存储位置、开机自动开启。
- CPU、内存和网络监控。
- 当前限制：实例未设置 Docker 路径，服务未启动；镜像、容器、网络和 Compose 深层管理未显示。
- DevBox 已有 Docker Compose 需求：GitHub Issue `#2`，新增规划应与其关联，避免重复。

## 7. 备份

- 创建备份任务。
- “备份飞牛”：目标可为远程服务器、外接设备或本机其他目录。
- “备份远程存储”：目标为本机 fnOS。
- 当前限制：未进入可能创建任务的向导，因此计划、保留策略、历史任务等未确认。

## 8. 资源管理

- 一级视图：运行状态、进程管理。
- 运行状态：总览、CPU、内存、网络、硬盘读写和硬盘摘要。
- 进程管理：“服务 / 进程”双视图。
- 服务指标：CPU、CPU 时间、内存、磁盘读写、端口、网络。
- 进程指标：进程名、PID、用户、状态、CPU、时间、内存、磁盘、端口、网络。

## 9. 日志

- 按等级、模块筛选。
- 字段：等级、模块、时间、用户、事件。
- 清空、更多操作、分页、每页条数和跳页。
- 可观察登录连接和硬盘存储等系统事件。

## 10. 调研边界

以下功能因实例前置条件不足或操作会改变系统状态而未验证：

- 创建存储空间后的真实文件、团队目录和回收站内容。
- 应用安装、更新、卸载及安装后运行页面。
- Docker 存储路径配置、服务启停以及后续镜像/容器/网络/Compose 页面。
- 备份任务向导提交、调度、版本保留和恢复。
- FN Connect、DDNS、SMTP、UPS、SSH、防火墙和共享协议的实际连通性。
- 系统更新、还原、重置及许可证购买。
